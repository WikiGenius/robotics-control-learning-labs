# Related projects

The [main index](../README.md) groups the public control projects and their current status.

| Project | Role |
| --- | --- |
| [iPendulum](https://github.com/WikiGenius/ipendulum) | State feedback, observers, PID, and MATLAB/Simulink studies |
| [WMM planning and tracking](https://github.com/WikiGenius/wmm-planning-and-tracking) | Mobile-manipulator trajectory generation and tracking in simulation |
| [Cruise Control](https://github.com/WikiGenius/Cruise_control) | Modeling and control exercises |
| [Screw Theory Toolkit](https://github.com/WikiGenius/RoboticScrewTheoryToolkit) | Kinematics, Jacobians, and inverse kinematics |

These projects support the execution side of perception-aware motion planning: feasible motion, feedback, and state estimation. They are separate educational and simulation implementations, not an integrated sensing-aware controller.

The [line-scan application scaffold](https://github.com/WikiGenius/line-scan-mobile-manipulator-demo) is a possible future integration case. It has no complete runnable demo. Other sensors and robot platforms can motivate different applications of the same control foundations.
